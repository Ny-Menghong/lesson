Introduction

Python is prized for reading almost like plain English. Unlike HTML, CSS and JavaScript, Python normally runs on a server or your own machine rather than in the browser — so in this lesson you'll read code and its output rather than run it live in-page.

Chapter 1: Variables & Types

Python variables need no keyword — just a name and a value. Python figures out the type automatically: integers, floats, strings, and booleans are the basics.

variables.py
student_name = "Maya"
courses_completed = 2
average_score = 8.5
is_enrolled = True

print(type(student_name))
print(type(courses_completed))
Note

Predicted output:

output
<class 'str'>
<class 'int'>

Python uses indentation — not curly braces — to mark blocks of code. Consistent 4-space indentation isn't a style choice here, it's required syntax.

Chapter 2: Conditionals

Python conditionals read almost like a sentence: if, elif, else, each followed by a colon and an indented block.

conditionals.py
score = 8

if score == 10:
    print("Perfect score!")
elif score >= 6:
    print("Nice job — review the ones you missed.")
else:
    print("Keep practicing.")
Note

Predicted output:

output
Nice job — review the ones you missed.
Warning

Forgetting the colon (:) at the end of an if line, or mixing tabs and spaces for indentation, are the two most common beginner syntax errors in Python.

Chapter 3: Loops

A for loop repeats code once per item in a sequence. Python's range() generates a sequence of numbers, and looping directly over a list is idiomatic Python.

loops.py
courses = ["HTML", "CSS", "JavaScript", "Python", "PHP"]

for course in courses:
    print(f"Studying {course}")

for i in range(3):
    print(f"Repetition {i}")
Note

Predicted output:

output
Studying HTML
Studying CSS
Studying JavaScript
Studying Python
Studying PHP
Repetition 0
Repetition 1
Repetition 2
Tip

f"Studying {course}" is an f-string — Python's equivalent of JavaScript's template literals. It's the standard way to build strings with variables inside them.

Practice

Exercise

Practice Challenge

Write a loop that prints "Even" or "Odd" for each number from 1 to 5, using the modulo operator %.

See a sample solution
solution
for n in range(1, 6):
    if n % 2 == 0:
        print(f"{n}: Even")
    else:
        print(f"{n}: Odd")

# Output:
# 1: Odd
# 2: Even
# 3: Odd
# 4: Even
# 5: Odd
