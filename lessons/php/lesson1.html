Introduction

PHP runs on the server, generating the HTML that gets sent to a visitor's browser before they ever see the page — it's what powers a huge share of the web, including WordPress. This lesson covers PHP tags, variables, and conditionals.

Chapter 1: PHP Tags & Echo

PHP code lives between <?php and ?> tags, often mixed directly into an HTML file. The echo statement outputs text into the page.

index.php
<!DOCTYPE html>
<html>
<body>
  <h1><?php echo "Welcome to CodeForge Academy"; ?></h1>
</body>
</html>
Note

Rendered output (the HTML the visitor's browser receives):

output
<h1>Welcome to CodeForge Academy</h1>

Chapter 2: Variables & Concatenation

PHP variables always start with a dollar sign. Join strings together with the . operator.

variables.php
<?php
$name = "Maya";
$coursesCompleted = 2;

echo "Hello, " . $name . "! You have completed " . $coursesCompleted . " courses.";
?>
Note

Predicted output:

output
Hello, Maya! You have completed 2 courses.
Tip

Double-quoted PHP strings can interpolate variables directly: "Hello, $name!" works the same as concatenating with ., and is often easier to read.

Chapter 3: Conditionals

PHP conditionals look almost identical to JavaScript's — if, elseif, else with curly braces.

conditionals.php
<?php
$score = 8;

if ($score === 10) {
  echo "Perfect score!";
} elseif ($score >= 6) {
  echo "Nice job!";
} else {
  echo "Keep practicing.";
}
?>
Note

Predicted output:

output
Nice job!
Warning

PHP's keyword is elseif (one word) inside this chained form, unlike JavaScript's else if (two words) — mixing them up is a common source of syntax errors for learners coming from JS.
