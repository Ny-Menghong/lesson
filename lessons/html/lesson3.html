Lists, Tables & Forms

⏱ 22 min ● Beginner
Course progress0 / 3 lessons complete (0%)
4:02 — Lists, tables and forms

Introduction

This lesson covers three workhorse elements: lists for grouping related items, tables for tabular data, and forms for collecting input from visitors.

Chapter 1: Lists

Use <ul> for an unordered (bulleted) list and <ol> for an ordered (numbered) one. Each item goes inside an <li>.

lists.html
<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

<ol>
  <li>Write the markup</li>
  <li>Style it with CSS</li>
  <li>Add behavior with JavaScript</li>
</ol>

Chapter 2: Tables

A table is built from rows (<tr>) containing header cells (<th>) or data cells (<td>), inside a <table>.

tables.html
<table>
  <tr>
    <th>Course</th>
    <th>Lessons</th>
  </tr>
  <tr>
    <td>HTML</td>
    <td>3</td>
  </tr>
  <tr>
    <td>CSS</td>
    <td>2</td>
  </tr>
</table>
Note

Tables are for tabular data — rows and columns that relate to each other. Don't use a table to lay out an entire page; that's what CSS Flexbox and Grid are for.

Chapter 3: Forms

A <form> collects input. Each field needs a matching <label> connected by a shared id/for pair, so clicking the label focuses the field — and so screen readers announce it correctly.

forms.html
<form>
  <label for="name">Your name</label>
  <input type="text" id="name" name="name" required>

  <label for="email">Email</label>
  <input type="email" id="email" name="email" required>

  <label for="plan">Choose a plan</label>
  <select id="plan" name="plan">
    <option>Free</option>
    <option>Pro</option>
  </select>

  <button type="submit">Sign Up</button>
</form>
Tip

Add required to a field and the browser will refuse to submit the form until it's filled in — no JavaScript needed.

Warning

A form on its own does not send data anywhere; you need an action attribute and a server (or JavaScript) to actually process a submission.
