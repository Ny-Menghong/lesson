Your First HTML Page

⏱ 15 min ● Beginner
Course progress0 / 3 lessons complete (0%)
3:12 — Building your first HTML page

Introduction

Every website you have ever visited is built, at its core, out of HTML — HyperText Markup Language. HTML does not make a page look pretty; it describes what each piece of content is: a heading, a paragraph, a list, an image. Browsers read that structure and render it. In this lesson you will write your first complete HTML document from scratch.

Note

HTML files use the .html extension. You can open one directly in any browser — no server or install required.

Chapter 1: The Document Skeleton

Every HTML page starts with the same four pieces: a doctype declaration, an <html> root element, a <head> for metadata, and a <body> for visible content.

index.html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My First Page</title>
</head>
<body>
  <h1>Hello, world!</h1>
</body>
</html>

<!DOCTYPE html> tells the browser to use modern HTML5 rules. The lang attribute on <html> tells screen readers and search engines what language the page is written in. Nothing inside <head> is shown on the page itself — it is metadata like the character encoding and the browser tab title.

Tip

Always include <meta charset="UTF-8">. Without it, special characters like curly quotes or emoji can render as garbled symbols.

Chapter 2: Headings and Paragraphs

HTML gives you six heading levels, <h1> through <h6>, in decreasing importance, and <p> for paragraphs of body text.

headings.html
<h1>Page Title</h1>
<h2>Section Heading</h2>
<h3>Sub-section Heading</h3>
<p>This is a paragraph of regular text. Paragraphs
are block-level, so each one starts on its own line.</p>
  • Use exactly one <h1> per page — it is the main title.
  • Never skip levels just to make text smaller; use CSS for sizing instead.
  • Screen reader users often jump between headings, so the order matters for accessibility.
Warning

Don't choose a heading level because of how big it looks. <h3> styled to look huge with CSS still tells assistive technology it's a third-level heading.

Chapter 3: Comments and Whitespace

You can leave notes in your HTML that the browser ignores completely, using <!-- comment -->. Browsers also collapse extra whitespace and line breaks in your source code down to a single space when rendering text.

comments.html
<!-- This is a comment, it will not display -->
<p>Extra   spaces     and
line breaks in the source
collapse into single spaces here.</p>

Practice Challenge

Write a complete HTML document with the correct doctype, a lang attribute, a page title of your choice in <head>, one <h1>, and two paragraphs describing yourself.

solution

<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>About Me</title>
</head>
<body>
  <h1>About Me</h1>
  <p>I am learning HTML with CodeForge Academy.</p>
  <p>My goal is to build my own website.</p>
</body>
</html>
