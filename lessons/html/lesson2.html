Text, Links & Images

⏱ 18 min ● Beginner
Course progress0 / 3 lessons complete (0%)
3:45 — Text, links and images

Introduction

A page of plain paragraphs is easy to write but hard to read. This lesson covers the elements that give text emphasis, connect pages together with links, and bring in images.

Chapter 1: Text Formatting

Use <strong> for text that is important and <em> for text that is emphasized. Both carry meaning, not just a visual style — screen readers announce them differently than plain text.

text.html
<p><strong>Warning:</strong> this action <em>cannot</em> be undone.</p>
<p>Line one.<br>Line two, right below it.</p>
Note

<b> and <i> also exist and look the same visually, but they carry no semantic meaning. Prefer <strong>/<em> unless you specifically need a stylistic bold or italic with no importance attached.

Chapter 2: Links

The anchor element <a> creates a hyperlink. Its href attribute is the destination — another page, a section of the same page, an email address, or an external site.

links.html
<a href="https://developer.mozilla.org">Visit MDN</a>
<a href="about.html">About this site</a>
<a href="#quizBox">Jump to the quiz</a>
<a href="mailto:hello@example.com">Email us</a>

Add target="_blank" to open a link in a new tab. When you do, also add rel="noopener" to prevent the new page from getting a reference back to your window.

external.html
<a href="https://example.com" target="_blank" rel="noopener">External site</a>
Warning

Never use a bare URL as your only clue — write descriptive link text like "Read the pricing guide" instead of "click here", since screen reader users often browse a list of link text out of context.

Chapter 3: Images

The <img> element embeds an image. It is a void element — it has no closing tag and no content, only attributes. src points to the file; alt describes it in words.

images.html
<img src="images/logo.png" alt="CodeForge Academy logo" width="120">
Tip

The alt text is read aloud by screen readers and shown if the image fails to load. Describe what the image shows or means — never leave it blank unless the image is purely decorative (then use alt="").
