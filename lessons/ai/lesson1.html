Introduction

Artificial Intelligence is about building programs that act intelligently. In this lesson we'll focus on core concepts: agents, search, knowledge representation, and learning. We'll implement a simple rule-based agent in Python to see AI in action.

Chapter 1: What is an AI Agent?

An agent perceives its environment and acts upon it. Think of a thermostat: it senses temperature and turns heating on/off. A chatbot perceives text and replies. In Python, an agent is often a function or class that maps inputs to actions.

agent.py
class SimpleAgent:
    def __init__(self, name):
        self.name = name

    def act(self, perception):
        # simple rule: if perception > 10, say "too much"
        if perception > 10:
            return f"{self.name} says: too much!"
        else:
            return f"{self.name} says: all good."

agent = SimpleAgent("AI-1")
print(agent.act(5))
print(agent.act(12))
Predicted output
output
AI-1 says: all good.
AI-1 says: too much!

Chapter 2: Search & Problem Solving

Search is a cornerstone of AI. Many problems (like pathfinding, puzzle solving) can be framed as finding a sequence of actions to reach a goal. Here's a simple brute‑force search for a numeric target.

search.py
def find_target(target, max_tries=20):
    for guess in range(max_tries):
        if guess == target:
            return f"Found {target} at try {guess}"
    return f"Not found in {max_tries} tries"

print(find_target(7))
print(find_target(25))
Predicted output
output
Found 7 at try 7
Not found in 20 tries

Chapter 3: Knowledge & Rules

AI systems often encode knowledge as rules: if condition, then conclusion. A simple expert system can make decisions. This is how early AI (e.g., MYCIN) worked.

rules.py
def diagnose(symptoms):
    if "fever" in symptoms and "cough" in symptoms:
        return "Possible flu"
    elif "rash" in symptoms and "fever" not in symptoms:
        return "Possible allergy"
    else:
        return "Unclear — consult a doctor"

print(diagnose(["fever", "cough"]))
print(diagnose(["rash"]))
Predicted output
output
Possible flu
Possible allergy
AI in practice

Modern AI often combines rules with learned models (machine learning). But rule‑based systems are still used in business logic, chatbots, and games.

Chapter 4: Introduction to Learning

Learning means improving from data. A simple form is linear regression: find a line that fits points. Here's a minimal implementation using ordinary least squares.

learn.py
# simple linear regression (slope only)
def learn_slope(xs, ys):
    n = len(xs)
    sum_x = sum(xs)
    sum_y = sum(ys)
    sum_xy = sum(x * y for x, y in zip(xs, ys))
    sum_x2 = sum(x * x for x in xs)
    slope = (n * sum_xy - sum_x * sum_y) / (n * sum_x2 - sum_x * sum_x)
    return slope

xs = [1, 2, 3, 4]
ys = [2, 4, 6, 8]   # perfect line y = 2x
print(round(learn_slope(xs, ys), 2))
Predicted output
output
2.0

Exercise

Build a recommendation agent

Write a function recommend(mood) that returns a movie genre based on mood: "happy" → "comedy", "sad" → "drama", "excited" → "action", else "documentary".

See a sample solution
solution
def recommend(mood):
    if mood == "happy":
        return "comedy"
    elif mood == "sad":
        return "drama"
    elif mood == "excited":
        return "action"
    else:
        return "documentary"

print(recommend("happy"))  # comedy
print(recommend("tired"))  # documentary
