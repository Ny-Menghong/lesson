សេចក្តីផ្តើមអំពី YOLO (You Only Look Once)

តើ YOLO ជាអ្វី?

YOLO (You Only Look Once) គឺជា Model សម្រាប់រកវត្ថុ (Object Detection) ដែលអាចមើលរូបភាពតែមួយដងប៉ុណ្ណោះ ហើយអាចទាយបានទាំងទីតាំង (Location) និងប្រភេទវត្ថុ (Class) ក្នុងពេលតែមួយ។ វាធ្វើឲ្យប្រព័ន្ធមានល្បឿនលឿនខ្លាំង និងអាចប្រើបានក្នុងការងារពេលវេលាពិត (Real-time) ដូចជា Camera, Self-driving car និង AI Surveillance។

✨ ចំណុចសំខាន់៖ YOLO ខុសពី model ដទៃ (ដូចជា R-CNN) ត្រង់ថាវាដំណើរការរូបភាពទាំងមូលក្នុងពេលតែមួយ មិនមែនចែកជាផ្នែកៗទេ។ នេះធ្វើឲ្យវាលឿនជាង ១០០ ដង។

តើ YOLO ដំណើរការយ៉ាងដូចម្តេច?

YOLO ប្រើ Neural Network តែមួយដើម្បីទាយវត្ថុក្នុងរូបភាព។ វាមានជំហានសំខាន់ៗ៖

១ បែងចែករូបភាព

YOLO បែងចែករូបភាពជាក្រឡាតូចៗ (grid) ឧ. ៧×៧ ឬ ១៩×១៩។ ក្រឡានីមួយៗទទួលខុសត្រូវលើការទាយវត្ថុដែលស្ថិតនៅក្នុងតំបន់របស់ខ្លួន។

២ ទាយ Bounding Box

ក្រឡានីមួយៗទាយប្រអប់ (bounding boxes) ចំនួនច្រើន រួមទាំងទីតាំង (x, y, width, height) និងភាពជឿជាក់ (confidence score)។

៣ ចាត់ថ្នាក់វត្ថុ

ក្រឡានីមួយៗទាយប្រូបាប៊ីលីតេសម្រាប់ថ្នាក់នីមួយៗ (ឧ. ឆ្កែ, ឆ្មា, ឡាន) ដោយប្រើ Softmax ឬ Sigmoid។

៤ Non-Maximum Suppression

យកប្រអប់ដែលមានភាពជឿជាក់ខ្ពស់បំផុត ហើយលុបប្រអប់ផ្សេងទៀតដែលត្រួតគ្នា (overlap) ច្រើន។

# ឧទាហរណ៍កូដ Python សម្រាប់ប្រើ YOLO (pseudo)
import cv2
import numpy as np

# ផ្ទុក model YOLO
net = cv2.dnn.readNet("yolov3.weights", "yolov3.cfg")

# ផ្ទុករូបភាព
img = cv2.imread("image.jpg")
height, width = img.shape[:2]

# បង្កើត blob និង forward pass
blob = cv2.dnn.blobFromImage(img, 1/255.0, (416, 416), swapRB=True)
net.setInput(blob)
outputs = net.forward()

# ដំណើរការលទ្ធផល
for output in outputs:
    for detection in output:
        scores = detection[5:]
        class_id = np.argmax(scores)
        confidence = scores[class_id]
        if confidence > 0.5:
            print(f"រកឃើញ {class_id} ជាមួយ confidence {confidence}")

កំណែរបស់ YOLO

YOLO មានកំណែជាច្រើន ដែលនីមួយៗមានភាពប្រសើរឡើង៖

YOLOv1 (2016) YOLOv2 (2017) YOLOv3 (2018) YOLOv4 (2020) YOLOv5 (2020) YOLOv8 (2023)
  • YOLOv1 — កំណែដំបូង លឿនប៉ុន្តែមានកំហុសច្រើន។
  • YOLOv3 — ប្រើ Feature Pyramid Network (FPN) សម្រាប់រកវត្ថុតូចៗបានល្អជាង។
  • YOLOv8 — កំណែថ្មីបំផុត មានភាពត្រឹមត្រូវខ្ពស់ និងគាំទ្រ segmentation ផងដែរ។

គុណសម្បត្តិ និងគុណវិបត្តិ

✅ គុណសម្បត្តិ

  • លឿនខ្លាំង (អាចដំណើរការបាន 45-155 FPS)
  • មើលរូបភាពទាំងមូល → យល់ពីបរិបទ
  • ងាយស្រួលប្រើ និងមាន pre-trained weights

⚠️ គុណវិបត្តិ

  • ពិបាករកវត្ថុតូចៗ ឬវត្ថុដែលនៅជិតគ្នា
  • ត្រូវការ GPU សម្រាប់ដំណើរការលឿន
  • ការហ្វឹកហាត់ (training) ត្រូវការទិន្នន័យច្រើន
