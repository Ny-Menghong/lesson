Introduction

JavaScript is what makes web pages interactive — it runs in the browser and can react to clicks, change what's on screen, and talk to servers. This lesson covers the basics: variables, data types, and writing your own functions.

Chapter 1: Variables & Types

Declare variables with let (can change later) or const (cannot be reassigned). Avoid the older var. JavaScript has a handful of core types: strings, numbers, booleans, arrays, and objects.

variables.js
let studentName = "Maya";
const coursesCompleted = 2;
let isEnrolled = true;

const favoriteTopics = ["HTML", "CSS", "JavaScript"];
const profile = { name: studentName, level: "beginner" };

console.log(typeof studentName); // "string"
console.log(typeof coursesCompleted); // "number"
Note

Use const by default. Only switch to let when you actually need to reassign the variable later — it makes code easier to reason about.

Chapter 2: Operators & Conditionals

Comparison operators like === (strictly equal) and logical operators like && and || let you branch with if/else.

conditionals.js
const score = 8;

if (score === 10) {
  console.log("Perfect score!");
} else if (score >= 6) {
  console.log("Nice job — review the ones you missed.");
} else {
  console.log("Keep practicing.");
}
Warning

Always use === and !==, not ==/!=. The loose versions convert types before comparing, which causes surprising bugs like "0" == 0 being true.

Chapter 3: Functions

A function packages up reusable logic. You can declare one with the function keyword, or write a shorter arrow function.

functions.js
function greet(name) {
  return `Hello, ${name}!`;
}

const double = (n) => n * 2;

console.log(greet("Sam"));   // "Hello, Sam!"
console.log(double(21));     // 42
Tip

Template literals — backticks with ${...} inside — let you build strings without messy + concatenation.
