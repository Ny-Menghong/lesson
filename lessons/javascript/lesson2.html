The DOM & Events

6:05 — The DOM and events

Introduction

The DOM (Document Object Model) is the browser's live representation of your HTML — a tree of objects that JavaScript can read and change. This lesson covers selecting elements, changing them, and responding to events like clicks.

Chapter 1: Selecting Elements

document.querySelector() finds the first element matching a CSS selector; document.querySelectorAll() finds all of them.

select.js
const title = document.querySelector("h1");
const allButtons = document.querySelectorAll("button");

console.log(title.textContent);
console.log(allButtons.length);

Chapter 2: Changing Content & Style

Once you have an element, you can change its text with textContent, its markup with innerHTML, or its appearance directly via .style — though toggling a CSS class is usually cleaner.

modify.js
const title = document.querySelector("h1");
title.textContent = "Welcome back!";
title.style.color = "#2E8B8B";

document.querySelector(".card").classList.add("highlighted");
Warning

Only use innerHTML with content you trust. Inserting untrusted user input with innerHTML can let attackers run malicious scripts on your page.

Chapter 3: Event Listeners

addEventListener runs a function whenever something happens — a click, a keystroke, a form submission.

events.js
const button = document.querySelector("#markCompleteBtn");

button.addEventListener("click", function () {
  console.log("Button was clicked!");
  button.textContent = "Done!";
});
Tip

This exact pattern — addEventListener("click", ...) — is what powers the Mark as Completed button and the quiz on this very page.

Exercise

Practice Challenge

Select a button with id toggleBtn and add a click listener that toggles a class named active on it.

See a sample solution
solution
const btn = document.getElementById("toggleBtn");
btn.addEventListener("click", () => {
  btn.classList.toggle("active");
});
