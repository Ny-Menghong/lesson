Flexbox Layout

⏱ 24 min ● Intermediate
Course progress0 / 2 lessons complete (0%)
5:10 — Flexbox layout from scratch

Introduction

Flexbox is a one-dimensional layout system built for arranging items in a row or a column, distributing space between them, and aligning them — without floats or manual positioning math.

Chapter 1: Turning On Flex

Set display: flex on a container, and its direct children become flex items that line up in a row by default.

flex.css
.nav-links {
  display: flex;
  flex-direction: row;
  gap: 12px;
}
flex.html
<ul class="nav-links">
  <li>Home</li>
  <li>Courses</li>
  <li>Contact</li>
</ul>
Note

gap adds space between flex items without needing margin tricks, and it works the same way in CSS Grid too.

Chapter 2: Justify & Align

justify-content controls spacing along the main axis (horizontal, by default); align-items controls alignment on the cross axis (vertical, by default).

justify-align.css
.toolbar {
  display: flex;
  justify-content: space-between; /* push items to the edges */
  align-items: center;            /* vertically center them */
  height: 64px;
}
  • justify-content: center — bunch items in the middle
  • justify-content: space-between — push first/last to the edges, evenly space the rest
  • align-items: center — vertically center items in the row

Chapter 3: Wrapping & Responsive Rows

By default flex items try to squeeze onto one line. Add flex-wrap: wrap to let them drop onto new rows on small screens, and use flex shorthand to control how each item grows or shrinks.

responsive.css
.card-row {
  display: flex;
  flex-wrap: wrap;
  gap: 20px;
}

.card-row .card {
  flex: 1 1 240px; /* grow, shrink, minimum 240px wide */
}
Tip

flex: 1 1 240px reads as "grow to fill space, shrink if needed, but never go below 240px" — a common pattern for responsive card grids without media queries.
