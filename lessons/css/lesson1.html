Selectors, Colors & the Box Model

⏱ 20 min ● Beginner
Course progress0 / 2 lessons complete (0%)
4:20 — Selectors, color and the box model

Introduction

CSS (Cascading Style Sheets) controls how HTML looks: colors, fonts, spacing, and position. This lesson covers how to target elements with selectors, how color and typography work, and the box model — the single most important concept in CSS layout.

Chapter 1: Selectors

A selector tells the browser which elements a rule applies to. The three you will use constantly are the element selector, the class selector, and the id selector.

style.css
p {
  color: #333;
}

.highlight {
  background: yellow;
}

#main-title {
  font-size: 2rem;
}
index.html
<h1 id="main-title">Welcome</h1>
<p class="highlight">This paragraph is highlighted.</p>
<p>This one is not.</p>
Note

Classes (.highlight) can be reused on many elements. IDs (#main-title) must be unique per page — use them sparingly, mostly for page anchors and JavaScript hooks.

Chapter 2: Color & Typography

Colors can be named (red), hex (#E8A33D), or rgb()/rgba() for transparency. Typography properties control the font family, size, weight and line spacing.

typography.css
body {
  font-family: "Inter", sans-serif;
  font-size: 16px;
  line-height: 1.6;
  color: #1B2430;
}

h1 {
  font-weight: 700;
  color: rgba(27, 36, 48, 0.9);
}
Tip

Set line-height to around 1.5–1.7 for body text. Cramped line spacing is one of the most common readability mistakes.

Chapter 3: The Box Model

Every element is a rectangular box made of four layers, from the inside out: content, padding, border, and margin. Padding is space inside the border; margin is space outside it, separating the element from its neighbors.

box-model.css
.card {
  width: 240px;
  padding: 20px;
  border: 2px solid #2E8B8B;
  margin: 16px;
  box-sizing: border-box;
}
Warning

By default, width only sets the content area — padding and border are added on top, making the box wider than you expect. Setting box-sizing: border-box makes width include padding and border instead, which is far more predictable.
